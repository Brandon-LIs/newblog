## 为什么做这个

图床这个东西，我自己前后折腾过好几版。早期用的各种免费图床不是要登录就是要审核，要么就是突然停服，图片全挂。作为一个博客重度用户，我太清楚"图挂了"有多让人崩溃了——存档的截图、文章里的配图，一旦源站没了就再也找不回来。

后来我干脆自己搭了一个。最初只是给自己用，后来越用越顺手，身边的朋友也开始问能不能借用，我一想：干脆做成**公益图床**开放出来，反正成本也不高，能帮一个是一个。

于是就有了 **[image.oopss.top](https://image.oopss.top)**。

## 它长什么样

界面很简洁，打开就是上传页：拖拽图片进去，或者点图标选择文件，可以多张一起传。

![image.oopss.top 上传界面](https://jsd.oopss.top/img/1788166333703.webp)

上传完自动生成一排链接格式，让你一键复制：

- **URL**：纯链接，贴哪都能用
- **HTML**：`<img>` 标签
- **BBCode**：论坛用的 `[img]`
- **Markdown**：写作最常用
- **Markdown with link**：带链接的写法

写博客、发论坛、做聊天表情包，基本覆盖了所有场景。

## 技术实现

底层用的是 **兰空图床（Lsky Pro）**，一个成熟的开源图床程序，自带丰富的 API；我把它接上 **Vercel** 做全球边缘部署，再套一层 **jsDelivr 全球 CDN**（`jsd.oopss.top`），保证国内国外访问都快。

核心链路大概是：

```
用户上传 → Vercel 服务处理（转 WebP / 压缩） → 存储 → jsDelivr CDN 分发
```

所以图片的最终访问地址长这样：

```
https://jsd.oopss.top/img/1788165998214.webp
```

这地址是 `jsd.oopss.top` 打头的，就是走 CDN 的稳定外链，博客里直接引用就能稳定显示。

## API 免费开放

除了网页上传，我也把接口免费开放了。**兼容兰空图床 Lsky Pro V2 标准**，所以 **PicGo / Typora / uPic** 这些常用工具都能直接配：

- 接口地址：`/api/v1/upload`
- 请求方式：`POST`
- 内容类型：`multipart/form-data`
- 文件字段名：`file`（同时兼容 `image` / `smfile`）
- **Token 留空即可**，不用填任何密钥

也就是说，你只要在 PicGo 里选「兰空图床 V2」、填上接口地址、Token 留空，就能一键上传，写 Markdown 的时候截图直接往图床一甩，自动生成 `![](url)` 格式，超级省心。

### 请求示例

```bash
curl -X POST https://image.oopss.top/api/v1/upload \
  -F "file=@photo.jpg"
```

### 返回示例

```json
{
  "status": true,
  "message": "upload success",
  "data": {
    "key": "1735632000000",
    "name": "1735632000000.webp",
    "pathname": "img/1735632000000.webp",
    "links": {
      "url": "https://jsd.oopss.top/img/1735632000000.webp",
      "markdown": "![...](...)",
      "bbcode": "[img]...[/img]"
    }
  }
}
```

另外还有一些进阶接口：原生上传 `/api/upload`、分片上传（大图自动分片）、带登录的图片列表 `/api/images` 和删除 `/api/delete`，方便二次开发。
