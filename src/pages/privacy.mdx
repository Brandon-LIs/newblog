# 隐私政策

欢迎访问 **Brandon's Blog**（以下简称"本站"，域名：blog.oopss.top）。我们重视你的隐私，并承诺依法保护你的个人信息。本政策说明本站收集哪些信息、如何使用、以及你的权利。

## 我们收集的信息

本站为个人博客，本身不注册账号、不要求登录。我们可能通过第三方服务收集以下信息：

- **日志信息**：访问时间、浏览器类型、来源页面等（由服务器/CDN 提供）。
- **统计信息**：通过不蒜子等统计服务匿名统计访问量（访客数、浏览量）。
- **评论信息**：评论区（Twikoo / GitHub）可能要求你提供昵称、邮箱、评论内容，用于显示和回复。
- **订阅信息**：通过 GitHub Issues 订阅更新时，GitHub 会记录你的账号信息（由 GitHub 处理，请参阅 [GitHub 隐私声明](https://docs.github.com/privacy)）。

## 信息的使用

- 用于本站的正常运行、内容展示与改进。
- 统计信息仅作匿名聚合，不用于识别个人。
- 评论内容仅用于评论展示与互动。

## Cookie 与追踪

本站可能使用少量 Cookie 或本地存储来记住你的浏览偏好（如主题模式）。这些 Cookie 不包含个人信息。

## 第三方服务

本站使用了以下第三方服务，其数据收集受各自隐私政策约束：

- **Vercel / Cloudflare**（托管与 CDN）
- **GitHub**（评论、订阅、图床）
- **Twikoo**（评论系统）
- **不蒜子 / Umami**（访问统计）
- **jsDelivr / jsd.oopss.top**（静态资源与图片加速）

## 你的权利

你有权：

- 查询、更正或删除你留下的评论信息。
- 通过评论系统或邮件（bcihal@qq.com）联系我们处理相关问题。
